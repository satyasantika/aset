# SIMAN FKIP 3 — Aset/BMN & Peminjaman

Sistem pengelolaan aset/BMN FKIP Universitas Siliwangi per barang (kode barang + NUP): lokasi, kondisi, label QR,
mutasi, peminjaman internal, pemeliharaan, DBR/DBL, inventarisasi, penghapusan, dan laporan. Pengganti
SIMAN-FKIP-2; melengkapi aplikasi resmi BMN Kemenkeu, tidak menggantikannya.
